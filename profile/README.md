# Websonette

Reusable building blocks, conventions, and development tools for modern PHP and Nette applications.

Websonette is being built around a few simple principles:

- small, focused packages with clear responsibilities;
- optional integrations instead of a monolithic framework;
- strict types, static analysis, and automated tests;
- practical conventions extracted from real applications;
- documentation designed for both developers and AI-assisted development.

The first public packages are currently being prepared.

## Packages

The ecosystem will cover these areas:

- application foundations for classic Nette web applications;
- optional localization and security integrations;
- reusable UI components;
- Vite and frontend tooling;
- project templates and shared coding standards.
