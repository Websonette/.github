# Security policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues or discussions.

Use GitHub's private vulnerability reporting feature in the affected repository when it is available. If private reporting is unavailable, contact the organization owner privately through their GitHub profile.

Include the affected package and version, reproduction steps, expected impact, and any known mitigation. Sensitive reports will be handled privately until a fix and coordinated disclosure are ready.

## Supported versions

Security fixes are normally provided for the latest supported major version of each package. Individual repositories may publish a more specific support policy.
